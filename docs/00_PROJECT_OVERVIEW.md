# MyPNR – Project Overview

MyPNR is a school management and tracking system developed for
PNR Sanat Akademisi, an arts academy offering ballet, dance, and music education.

The system is designed using Google AI Studios and integrated with Supabase
for authentication, database management, and security.

## Core Goals
- Manage student registrations and CRM
- Track lessons, attendance, and schedules
- Manage teachers, branches, and contracts
- Track income, expenses, and profitability
- Provide an artistic yet professional dashboard

## Technology Stack
- Frontend & UI: Google AI Studios
- Backend & Auth: Supabase
- Database Security: Supabase RLS
- Charts & Visualization: Built-in dashboard components

## Design Philosophy
Artistic, colorful, but balanced.
Colors are used to represent data, not decoration.
