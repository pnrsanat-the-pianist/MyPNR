# Permissions Matrix

Permissions are defined per role and page.

Each page supports:
- View
- Edit
- Delete

## Example
Admin:
- Full access to all pages

Kurucu:
- All operational pages
- No system-level technical settings

Müdür:
- Education & Finance view
- Limited edit rights

Öğretmen:
- Own students
- Own lessons
- Attendance only

Veli:
- Own child data (read-only)
